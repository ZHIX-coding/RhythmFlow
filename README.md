# 🎵 RhythmFlow — 音频驱动可视化与节奏应用

**RhythmFlow** 是一款基于 C++ / Qt6 开发的赛博朋克风格桌面应用。它不仅能实时将音乐转化为动态频谱和粒子星云，还内置了自动谱面生成的节奏游戏模式，同时兼具音乐播放器功能。按住按键，跟随鼓点，让星云在你的指尖舞动。

---

## ✨ 特性

- 🎧 **实时音频可视化**：64 段青白渐变频谱柱 + 2000 粒子星云背景，随音乐律动。
- 🎮 **自动谱面节奏游戏**：无需手动编辑谱面，程序自动检测鼓点生成下落音符。
- 🖱️ **粒子鼠标交互**：安静时粒子聚为星云核，左键点击粒子汇聚跟随鼠标，颜色从青色变为亮白；点击同时触发多圈涟漪扩散特效。
- 🖥️ **无边框透明悬浮窗**：窗口全透明，频谱柱和粒子仿佛悬浮在桌面上，支持拖动。
- 🎨 **赛博朋克视觉风格**：亮青/纯白配色，霓虹光晕轨道线，可自定义音符素材。
- 🔊 **击打音效与判定反馈**：成功击中音符播放自定义音效，并显示 Perfect / Good / Miss 特效。
- 🚀 **连击加速机制**：连击数越高，音符下落速度越快，挑战性递增。
- 🎵 **内置多首歌曲与播放器**：内置 14 首示例曲目，支持上一首/下一首、播放/暂停、顺序/单曲/随机播放模式。
- 🎞️ **GIF 录制功能**：一键录制当前画面，输出 GIF 动图，方便分享与演示。
- 🌟 **启动画面**：程序启动时显示深邃的粒子星云启动画面，平滑过渡到主界面。

## 🏗️ 软件架构

项目采用模块化设计，核心类职责如下：

| 类名 | 职责 |
|:---|:---|
| `AudioEngine` | MP3 播放、内部音频捕获、FFT 频谱计算、鼓点检测 |
| `Visualizer` | 所有绘制工作：频谱柱子、粒子系统（含鼠标交互）、涟漪特效、游戏界面（轨道/音符/分数） |
| `RhythmGame` | 游戏逻辑：音符生成、下落更新、判定、计分连击、连击加速 |
| `RhythmFlow` | 主窗口，串联上述模块，处理按键事件、播放列表管理、GIF 录制 |
| `SplashScreen`（`main.cpp` 内） | 程序启动动画，粒子背景与标题淡入淡出 |

**数据流**：  
`MP3 文件` → `AudioEngine` 解码 → FFT 频谱 + 鼓点信号 → `Visualizer` 绘制 / `RhythmGame` 生成音符

## 📦 安装教程

### 环境要求

- Windows 10 / 11
- Visual Studio 2022
- Qt 6.5+（必须包含 Multimedia 模块）
- CMake 或 Qt VS Tools 插件

### 编译步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/ZHIX-coding/RhythmFlow.git
   git clone https://gitee.com/zhix_coding/rhythm-flow.git

   ```

2. **配置 Qt 环境**
   - 安装 Qt 6.5+，确保勾选 `Qt Multimedia` 组件。
   - 在 Visual Studio 中安装 `Qt VS Tools` 插件，并配置 Qt 版本路径。

3. **打开项目**
   - 启动 Visual Studio，选择"打开本地文件夹"或直接打开 `.sln` 文件（如果已生成）。
   - 若使用 CMake，确保 `CMakeLists.txt` 中已正确链接 `Qt6::Multimedia`。

4. **编译运行**
   - 选择 `Debug x64` 配置，按 `F5` 生成并运行。

> **注意**：
> - 项目使用了第三方库 `kiss_fft` 和 `gif.h`，文件已包含在源码中，无需额外下载。
> - 内置歌曲、音符素材和音效文件通过 Qt 资源文件（`.qrc`）编译进可执行文件，发布时无需附带额外文件。

## 🎮 使用说明

### 基本操作

| 操作 | 按键/动作 |
|:---|:---|
| 打开 MP3 文件 | 点击窗口左上角 **MP3** 按钮 |
| 播放内置歌曲 | 点击 **Play** 按钮，从弹出菜单中选择一首歌曲 |
| 进入/退出游戏模式 | 按下 **空格键** |
| 游戏内击打音符 | **D / F / J / K**（对应 4 条轨道） |
| 暂停/恢复播放 | 数字键 **2** |
| 上一首 / 下一首 | 数字键 **1** / **3** |
| 切换播放模式 | 数字键 **4**（顺序循环 / 单曲循环 / 随机播放） |
| 录制 GIF 动图 | 按 **R** 键开始录制，再次按 R 或 5 秒后自动停止，文件保存到桌面 |
| 显示帮助 | 按 **F1** 或右键菜单选择 **Help** |
| 退出程序 | 右键窗口任意位置 → **Exit** |

### 鼠标交互

| 操作 | 效果 |
|:---|:---|
| **左键点击空白区域** | 2000 个粒子向鼠标点击位置聚拢，颜色由青色渐变为亮白偏青，同时生成 5 圈扩散涟漪 |
| **按住左键拖动** | 粒子跟随鼠标实时移动，聚拢中心随鼠标位置更新 |
| **松开左键** | 粒子逐渐恢复星云态，向屏幕中上部引力中心缓慢聚拢 |

> 鼠标交互在纯享模式和游戏模式下均有效。在游戏模式中，粒子透明度会略微降低，以突出游戏界面。

### 游戏玩法

1. 播放一首鼓点清晰的 MP3 音乐。
2. 按下空格键进入游戏模式，画面将出现 4 条轨道和判定线。
3. 随着音乐的鼓点，长条音符会从轨道上方下落。
4. 当音符到达判定线时，按下对应轨道的按键（D/F/J/K）即可得分。
5. 连续击中会累积连击数，获得更高分数加成，同时音符下落速度会逐渐加快，挑战性升级。
6. 错过音符连击会中断，判定线会短暂闪烁灰色。
7. 再次按下空格键可退出游戏模式，恢复纯享可视化。

### 自定义素材

你可以替换 `resources` 目录下的以下文件来改变外观：
- `note1.png` — 普通音符图片
- `note2.png` — 强拍音符图片
- `image1.png` — 击中特效图片
- `perfect.png` / `good.png` / `MISS.png` — 判定文字图片
- `Pickup.wav` — 击打音效

素材需保持相同文件名，并通过 `.qrc` 文件注册，程序会自动加载。
